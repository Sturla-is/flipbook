Privacy-safe event exports

Exports require an authenticated workspace member. They exclude session hashes, reader hashes, IP addresses, internal expiry fields, and unlisted metadata. Search events can contain reader-entered search text.

Events JSON Events CSV

Privacy and retention

Events expire automatically after the workspace retention period. Raw IP addresses are never stored. Referrers have query strings and fragments removed, bots and admin previews are filtered, and reader opt-out or DNT=1 stops collection.

Reader event fields and controls

The public endpoint is POST /api/public/flipbooks/{id}/events. Optional metadata consumed by the server:

event_id, placement, embed_host, target_url, query, cta_id, link_id, channel, method, format, and the five utm_* fields. Other metadata is discarded.

Readers can inspect policy at GET /api/public/flipbooks/{id}/analytics/privacy and grant or withdraw consent with POST /api/public/flipbooks/{id}/analytics/consent using {"consent":true} or {"consent":false}.
